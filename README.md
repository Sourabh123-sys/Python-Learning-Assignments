# Customer Sales Analysis

## Project Overview

This project analyzes customer purchasing behavior and sales performance using Python and Pandas. The objective is to identify sales trends, top customers, regional performance, and customer churn patterns.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Features

* Customer Analysis
* Sales Trend Analysis
* Product Performance Analysis
* Regional Analysis
* Customer Churn Analysis
* Pivot Tables
* Data Visualization

## Installation

pip install -r requirements.txt

## Run Project

jupyter notebook customer_analysis.ipynb

## Results

The project provides business insights regarding customer behavior, product demand, sales trends, and customer retention.
