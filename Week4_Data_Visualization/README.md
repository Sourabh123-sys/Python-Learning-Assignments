# Week 4: Data Visualization Project

## Project Overview
This project performs complete sales data analysis using Python, Pandas, and Matplotlib.

## Features
- Data loading and cleaning
- Statistical analysis
- Bar chart visualization
- Line chart visualization
- Pie chart visualization
- Report generation

## Technologies Used
- Python
- Pandas
- Matplotlib
- NumPy

## Setup Instructions

Install dependencies:

```bash
pip install -r requirements.txt
```

Run project:

```bash
python main.py
```

## Output
- Sales analysis report
- Visual charts saved in visualizations folder
