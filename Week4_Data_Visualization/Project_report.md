# E-commerce Sales Analysis Report

## Objective
Analyze sales dataset and visualize trends using charts.

## Analysis Performed
- Dataset loading
- Data exploration
- Missing value handling
- Revenue calculation
- Product-wise sales analysis

## Visualizations
### 1. Bar Chart
Shows total sales by product category.

### 2. Line Chart
Shows overall sales trend.

### 3. Pie Chart
Displays sales contribution percentage.

## Findings
- Certain products generated higher revenue.
- Sales distribution is uneven among products.
- Charts helped visualize business insights clearly.

## Conclusion
The project successfully demonstrated data analysis and visualization using Python libraries.
